# WinStateDiag v1.0 — release notes (draft)

WinStateDiag is a portable, read-only Windows diagnostic center with two pages: ДИАГНОСТИКА and ОБОРУДОВАНИЕ.

## Highlights

- **Evidence intelligence.** Event identity is now provider-exact: Hyper-V 41 is never Kernel-Power. Event groups are actionable and named by service, process and exception, and every counter has an explicit scope. VSS, pending reboot and GPO findings use honest severities. Code Integrity software findings are no longer dropped.
- **Drivers.** No "unsigned" warning without identity. Signatures are checked by Authenticode plus catalog. Package identity conflicts are flagged and never come with a delete advice.
- **Storage.**
  - SATA benchmarks with physically impossible results are rejected (BENCHMARK INVALID).
  - ATA SMART is the health source for SATA disks.
  - The NVMe error-log is compared as a delta between completed sessions.
  - Correlation scope, temperature provenance and session identity are recorded.
- **Crash analyzer.** It reads СОСТОЯНИЕ → ЧТО ОБНАРУЖЕНО → ИНЦИДЕНТЫ → ВЕРОЯТНАЯ ПРИЧИНА → ЧТО ПРОВЕРИТЬ, with the raw WinDbg output collapsed. LiveKernelReports are explained, and all counters come from one source. The WinDbg package and its cdb backend are detected independently of the winget exit text.
- **DISM Repair Intelligence** (read-only): historical vs current vs recurrent corruption.
- **UI.**
  - New right header logo.
  - BIOS line in the passport.
  - Larger journal, now carrying the report buttons.
  - Sensor READ spinner with a real timer.
  - The SMART block lists physical disks individually.
- **Sensors.** Only the safe provider chain is used. There is no WinRing0, and no driver is ever installed. Values without a safe source read «Нет данных».

## Safety

WinStateDiag never:

- repairs, deletes drivers or runs RestoreHealth;
- changes BIOS or virtualization settings;
- disables Windows security;
- installs PawnIO, HWiNFO or AIDA64.

WinDbg is installed only after an explicit click, from the official Microsoft package through winget, with the normal system UAC prompt.
