# WinStateDiag v1.1 — release notes (draft, not published)

## Highlights

- **Startup preflight.**
  - At launch these checks run in the background, read-only:
    - Driver Audit;
    - CryptoPro (presence, CSP version, licence key, HASH state);
    - WinDbg / cdb detection;
    - a crash / dump summary.
  - The GUI opens at once.
  - The preflight creates no session, ZIP or report, and joins no client report.
  - Every result shows its origin and time, e.g. «Предварительно · 16:05».
  - «Запустить диагностику» starts a separate full session with its own checks.
  - Closing the app cancels every background process.
- **CryptoPro card.** Compact layout: logo, round ⟳ re-check, status disc, status with time, «Детали».
  - Details show presence, version, licence and term, HASH state, last check, data source and errors, with Copy and Close.
  - «Выполнить ReHash» is separate. It shows a warning and needs an explicit confirmation, never runs during a check, and re-verifies the state afterwards.
- **Driver Audit.**
  - «Проверка» re-checks only this module, never twice at once. A successful result replaces the old one; a failed one keeps it.
  - Details keep a check history: [Копировать] [Сохранить отчёт] [Очистить журнал]. Clearing it asks first and never touches Windows logs or saved reports.
- **Hardware Passport 2.0.** One large scrollable window in the WinStateDiag palette.
  - Cards: CPU, memory, motherboard, BIOS/UEFI, storage, graphics, network, power/battery.
  - Configuration, current measurements and unconfirmed values are shown apart; there is no universal "OK".
  - Fixed footer: [Обновить] [Скопировать сводку] [Сохранить отчёт] [Закрыть].
- **Crash analyzer polish.**
  - MODULE_NAME / IMAGE_NAME / PROCESS_NAME are filled from the raw WinDbg text when the structured parse misses them.
  - PROCESS_NAME is never cut by the parser. WinDbg's own 14-character form is restored or marked.
  - NatVis and other debugger service noise is hidden from the main view; the raw evidence is unchanged.
  - Statuses read as words with the canonical id kept, e.g. «средняя (MEDIUM)».
  - Unchanged: the 0x139 → RvNetMP60.sys → Radmin VPN → MEDIUM correlation, and the historical-BSOD wording.

## Safety

The v1.0 safety rules are unchanged. WinStateDiag does not:

- repair anything;
- delete drivers;
- change BIOS or Windows security;
- install third-party components.
